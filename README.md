# Crypto Research System

## Цель

Системная исследовательская платформа для анализа криптоактивов.

## Как устроен проект

- **Skill** — единая методология проведения исследований.
- **GitHub Project** — управление исследовательскими задачами.
- **Issues** — конкретные вопросы и исследования.
- **Reports** — завершённые результаты.
- **Docs** — документация и правила системы.

## Методология

**Задача → Исследование → Факты → Анализ → Результат → Мониторинг**

Подробная методология и формат исследования определены в **CryptoResearch v1**.
