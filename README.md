# Crypto Research System

## Цель

Создать системную методологию исследования криптоактивов: от постановки задачи и сбора фактов до анализа, результата и последующего мониторинга.

## Методология

Каждый актив исследуется по единой схеме:

**Задача → Исследование → Факты → Анализ → Результат → Мониторинг**

### 1. Задача
Что именно необходимо выяснить и зачем это важно.

### 2. Исследование
Сбор необходимых данных и информации из проверяемых источников.

### 3. Факты
Зафиксированные данные без интерпретации.

### 4. Анализ
Интерпретация фактов, взаимосвязи, контекст и возможные объяснения.

### 5. Результат
Сводный вывод по поставленной исследовательской задаче.

### 6. Мониторинг
Показатели и события, которые необходимо отслеживать после завершения исследования.

## Структура исследования актива

Для каждого актива используем следующие блоки:

1. Суть проекта
2. Технология
3. Токеномика
4. Состояние сети
5. Экосистема
6. Пользователи и активность
7. Институциональное использование и капитал
8. Рынок
9. Макроэкономический контекст
10. Конкуренты
11. Риски
12. Катализаторы
13. Сценарии
14. Итог
15. Мониторинг

## Kanban workflow

В GitHub Project используются пять стадий:

- **BACKLOG** — вопросы и исследования, которые предстоит выполнить
- **RESEARCH** — активное исследование
- **ANALYSIS** — обработка и интерпретация собранных данных
- **RESULT** — завершённый исследовательский результат
- **MONITORING** — завершённые исследования, требующие регулярного обновления
